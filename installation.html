BRAVIA 9 II Installation & First Setup

This page provides a practical setup sequence. For wall mounting, electrical safety and exact terminal locations, follow the manual supplied with the exact model.

Safety first: A large 65-inch TV should be lifted by two people. Do not lift the display by the screen itself. For wall mounting, use a compatible bracket and follow Sony's mounting instructions for the exact model and wall type.

Before You Start

  • Choose a stable, level surface with adequate ventilation.
  • Keep the screen away from direct water, excessive heat and strong sources of vibration.
  • Make sure the power outlet is accessible after installation.
  • Prepare your Wi-Fi password and Google account details if you want to use online services.
  • For a console or media player, identify the HDMI port and cable you plan to use before routing cables.

Step-by-Step Initial Setup

  1. Position the TV: Place it securely on the supplied stand or install it with an appropriate wall mount.
  2. Connect power: Connect the AC power cable securely to the TV and a suitable wall outlet.
  3. Connect external devices: Connect an antenna, set-top box, game console, soundbar or other equipment as required.
  4. Power on: Press the Power button on the supplied remote.
  5. Select language and region: Follow the on-screen setup wizard.
  6. Connect to the internet: Select your Wi-Fi network or use a wired LAN connection if available.
  7. Sign in: Complete Google TV account setup if you want personalised apps and recommendations.
  8. Check updates: Allow the TV to install available software updates before extensive use.
  9. Set picture and sound: Choose a suitable picture mode and confirm the speaker output.

Recommended Connection Examples

Device Recommended connection Why
Game console Compatible HDMI connection Use a suitable HDMI cable and a port that supports the required gaming features.
Soundbar HDMI eARC/ARC Allows compatible audio return and easier system control.
Streaming player HDMI Provides digital video and audio through one connection.
Home network Wi-Fi 6E or Ethernet Choose the connection that gives the most reliable performance in your home.

Wi-Fi Setup

Open the network settings from the TV menu and select the available Wi-Fi network.

Settings → Network → Wi-Fi
  1. Select your network name (SSID).
  2. Enter the Wi-Fi password carefully.
  3. Wait for the connection test to complete.
  4. Open a streaming app to confirm internet access.

Remote Control Guide

The exact remote layout can vary by model, country and region.

Power

Turns the TV on or places it into standby/networked standby according to the configured settings.

Input Select

Switches between TV input sources and connected devices.

Quick Settings

Provides fast access to picture, sound, content type, sleep timer, picture-off and other options.

Navigation D-Pad

Moves through menus and confirms selections.

Back

Returns to the previous screen or menu.

Google Assistant / MIC

On compatible remotes, press and hold the microphone button while speaking.

Volume

Raises or lowers the TV audio level.

Mute

Temporarily disables TV audio; press again to restore it.

After Installation Checklist

  • TV is stable and safely positioned.
  • Power and signal cables are firmly connected.
  • Wi-Fi or Ethernet connection works.
  • Remote control operates correctly.
  • Sound output is set to the intended TV/soundbar device.
  • Software is updated.
  • Important streaming apps can open and play content.
Always follow the official setup and safety instructions for your exact BRAVIA model.
