Troubleshooting

Try the simplest checks first. If a problem continues, use the official manual/support page for the exact model.

Basic restart: Turn the TV off, disconnect power for about two minutes, reconnect it and turn it on again. This can clear temporary software or connection problems.

Power and Startup

TV does not turn on
  • Check that the power cable is firmly connected.
  • Test the wall outlet with another suitable device.
  • Try the TV's power control if the remote does not respond.
  • Replace the remote batteries if necessary.
  • Disconnect power for about two minutes and retry.
TV restarts or turns off unexpectedly
  • Check Sleep Timer and On/Off Timer settings.
  • Check for software updates.
  • Make sure ventilation openings are not blocked.
  • Disconnect recently added USB/HDMI devices temporarily and test again.

Picture

No picture or "No signal"
  • Press Input Select and choose the correct HDMI source.
  • Make sure the connected device is powered on.
  • Reconnect the HDMI cable at both ends.
  • Try another HDMI input and, if possible, another compatible cable.
  • Restart both the TV and the connected device.

Tip: If audio works but the screen is intentionally blank, check whether Picture Off is enabled.

Picture is too dark, too bright or colours look unusual
  • Open Quick Settings and try an appropriate Picture Mode.
  • Check that the Content Type matches the source.
  • For HDR content, confirm the source device and app are actually outputting HDR.
  • Reduce direct light or strong reflections on the screen.
  • If the problem affects only one app or input, compare with another source.
Motion looks unusual or game feels delayed
  • For gaming, check that the console is using a compatible HDMI connection.
  • Check the TV's game-related picture settings.
  • For supported devices, verify the expected refresh rate and VRR settings.
  • Try a different HDMI cable if the source cannot maintain the expected signal.

Sound

No sound or very low sound
  • Press Mute and increase the volume.
  • Open Quick Settings → Speakers and confirm the intended output.
  • Check the volume on a connected soundbar/receiver.
  • Reconnect HDMI eARC/ARC equipment if used.
  • Test with the built-in TV speakers to isolate an external-device problem.
Soundbar does not play TV audio
  • Use the HDMI port and connection method recommended by the soundbar/TV documentation.
  • Check that eARC/ARC and the correct speaker output are configured.
  • Restart both the TV and soundbar.
  • Try another compatible HDMI cable if the connection is unstable.

Network and Apps

Wi-Fi will not connect
  1. Open Network settings.
  2. Confirm Wi-Fi is enabled.
  3. Select the correct network name.
  4. Enter the password exactly; passwords are case-sensitive.
  5. Restart the router and TV.
  6. Test the same Wi-Fi network with a phone or laptop.

If only the TV fails: move the router closer if possible or use Ethernet where practical.

Apps are slow or videos keep buffering
  • Test internet speed using another device on the same network.
  • Restart the router and TV.
  • Close/reopen the affected app and check for app updates.
  • Reduce other high-bandwidth network activity.
  • If only one service is affected, check whether the service itself is experiencing an outage.
App will not open or crashes
  • Restart the TV.
  • Check the app for updates.
  • Check that the TV software is up to date.
  • Free storage if the TV is running low on available space.
  • If necessary, reinstall the affected app using the supported TV interface.

Remote and Voice

Remote does not respond
  • Replace the batteries or recharge the remote if applicable.
  • Make sure nothing is interfering with the remote.
  • Restart the TV.
  • Try the TV's own controls to confirm the TV is responsive.
Google Assistant / voice search does not respond
  • Press and hold the microphone/Assistant button while speaking, when required by the remote.
  • Confirm that the TV is connected to the internet.
  • Check microphone/privacy settings if voice control is unavailable.
  • Voice features and supported languages vary by country, region and software.

Connected Devices

Console, player or other HDMI device is not detected
  • Select the correct HDMI input.
  • Power-cycle the connected device.
  • Reconnect the HDMI cable.
  • Try another HDMI input.
  • Try another compatible high-speed HDMI cable.
  • For advanced gaming signals, verify the device's output settings and the TV's supported input mode.
USB device is not recognised
  • Reconnect the USB device.
  • Try the other USB port.
  • Check that the file system and media format are supported.
  • Test with another compatible USB device to isolate the problem.

When to Get Professional Help

Stop troubleshooting and seek qualified/official service if there is smoke, burning smell, physical damage, liquid inside the TV, repeated electrical arcing, a damaged power cable, or another condition that could create a safety risk. Do not open the TV yourself.

Still Need Help?

Record the exact model name, software version, input/device involved and the steps that reproduce the problem. This information can make official support much faster. Use Sony's support resources for the exact model and country/region.

For safety and model-specific repairs, use the official Sony documentation and support service.
